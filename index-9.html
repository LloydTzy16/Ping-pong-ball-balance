Teach the balls (AI training)

Mark the holes in the camera picture

Point the camera at the board so it sees the coloured rings. Press Find holes automatically, or press a Mark button and click on that hole's coloured ring. The page draws a circle round each hole. The circles follow the holes if you move the board (switch this off in the rules panel). The marked holes are also hidden from the ball tracking, so the rings are never mistaken for a ball.

Teach the hole sensors

Press a button, then put a ball into that coloured hole (or block its IR sensor). The ESP32 learns which sensor belongs to that colour and remembers it, so the wires can be in any order. A ball of the same colour as the hole = a point. A ball in a hole of another colour = game over.

Table setup for Supabase (run once) 
-- Run this in Supabase (safe to run again): SQL Editor -> New query -> paste -> Run
create table if not exists game_history (
  id bigint generated always as identity primary key,
  played_at timestamptz not null default now(),
  player_name text not null default 'Player',
  level int not null,
  level_name text,
  score int not null,
  balls_needed int,
  result text not null,
  reason text,
  seconds_left int
);

alter table game_history enable row level security;

-- the game page uses the public "anon" key: it may add results and read the list
drop policy if exists "game can add results" on game_history;
drop policy if exists "game can read results" on game_history;
create policy "game can add results" on game_history for insert to anon with check (true);
create policy "game can read results" on game_history for select to anon using (true);
